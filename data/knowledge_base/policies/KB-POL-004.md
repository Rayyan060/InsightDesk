# Account deletion policy

## Introduction

Deleting a CloudFlow account permanently removes all associated workspaces, workflows, run history, and stored credentials.

## Deletion requests

Only the account owner can request deletion. The support assistant does not handle deletion requests or schedule deletions. Instead, every request is reviewed by the account team, who will verify the owner's identity using the email address on file. Once confirmed, the account is disabled immediately, and its data is erased within 30 days. Outstanding invoices are not cancelled by a deletion request.

## Exporting data first

Before requesting deletion, make sure to export any necessary data, such as run history (KB-ADV-007) and workflow definitions (Workflows > ... > Export definition). Once data is deleted, it cannot be recovered.
