# Security and account access policy

## Introduction

This policy covers how to handle suspected security incidents, password resets, and the types of account data that support can discuss.

## Reporting a security incident

Treat any of the following as a security incident: a leaked or exposed API token, unexpected sign-ins, workflows you did not create, or a suspected compromise of a connected system. Report it to support immediately. Security reports go to the security queue at urgent priority and receive a first response within 1 hour (KB-POL-003). If a token may be exposed, revoke it at once in Settings > API tokens (4.x) or Settings > Developer (3.x); you do not need to wait for us.

## Password resets

Password resets are started only through CloudFlow's reset tool, which emails a single-use link to the owner email address on file for the account. The link expires after 30 minutes. Support staff and the assistant never see, type or paste reset links or tokens in a conversation, and the reset can never be redirected to another address.

## Account access

Support discusses only the account identified by the session you are signed in with. We do not disclose another account's plan, usage, invoices or contacts, even if you quote its account ID, and we refuse such requests.
