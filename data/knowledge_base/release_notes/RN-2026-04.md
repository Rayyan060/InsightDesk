# CloudFlow 4.2 release notes

## Highlights

- The run-history export feature has been redesigned to allow exporting data in CSV or JSON formats, with a maximum of up to 1,000,000 rows, and the ability to schedule exports (KB-ADV-007).
- A new API endpoint, `GET /v2/runs/export`, has been added.
- When rotating an API token, the old token remains valid for a 24-hour grace period (KB-API-014).
- The step time limit has been increased from 10 to 15 minutes.
