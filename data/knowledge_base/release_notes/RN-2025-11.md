# CloudFlow 4.0 release notes

## Highlights

- The new Flow editor has replaced the Classic editor.
- API tokens now include scopes and are sent as `Authorization: Bearer` in the new `/v2` API.
- OAuth connections now feature a **Reconnect** button.
- Per-step retry policies are now available.
- The step time limit has been increased from 5 to 10 minutes.

## Support for 3.x

CloudFlow 3.x will only receive security fixes. Standard support for 3.x ends on June 30, 2026.
