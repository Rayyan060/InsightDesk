# CloudFlow 4.3 release notes

## Highlights

- The run-history search is now faster.
- The usage page now displays the peak API requests per minute for the current month.

## Deprecation: legacy API keys

- Legacy API keys used by CloudFlow 3.x (identified by `X-CloudFlow-Key` on the `/v1` API) are deprecated and **stop working on 1 December 2026**.
- Workspaces still on version 3.x must upgrade to version 4.x and switch to API tokens before that date. For more information, see KB-API-001 and KB-API-002.

## Billing policy update

- Starting November 1, 2026, the refund window for Pro and Business plans is 7 days. For more information, see KB-POL-001.
