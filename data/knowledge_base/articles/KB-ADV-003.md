# Cron triggers

## Overview

Cron triggers are used to start a workflow based on a cron expression. To configure them, go to **Settings > Triggers > Cron**.

## Deprecation

Cron triggers are deprecated in CloudFlow versions 4.1 and later, and will stop working as of 30 June 2026. It is recommended to move to using Schedules (refer to KB-ADV-004 for more details).
