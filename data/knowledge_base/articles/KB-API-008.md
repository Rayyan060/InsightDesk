# Supported integrations

## Connector catalog

CloudFlow 4.x includes native connectors for Salesforce, HubSpot, Slack, Microsoft Teams, Google Sheets, Gmail, Jira, Zendesk, Stripe, Shopify, PostgreSQL, and Amazon S3. CloudFlow 3.x supports Salesforce, Slack, Google Sheets, and Gmail.

## Apps without a connector

Any service with an HTTP API can be used with the **HTTP request** step and a webhook trigger. CloudFlow does not build custom connectors on request, and an app that is not listed here is not supported natively.
