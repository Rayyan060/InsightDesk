# Slack and Microsoft Teams connectors

## Slack

To connect CloudFlow with Slack, go to **Connections > New connection > Slack** and select the channels where CloudFlow can post messages. Note that private channels require inviting the CloudFlow app to the channel.

## Microsoft Teams

To connect with Microsoft Teams, use a Microsoft 365 account that can install apps. Messages will be posted as the CloudFlow bot.

## Limits

Slack limits apps to about 1 message per second per channel. To stay within this limit, CloudFlow queues messages accordingly.
