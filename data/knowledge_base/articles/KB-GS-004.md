# Workspace roles and permissions

## Roles

CloudFlow accounts have predefined roles that determine what actions users can perform. Here's a breakdown of each role:

| Role | Can do |
|---|---|
| **Owner** | Everything, including billing, plan changes, and account deletion requests |
| **Admin** | Manage members, connections, and all workflows |
| **Editor** | Create and edit workflows, view run history |
| **Viewer** | View workflows and run history |

Each account has exactly one owner. If you have any billing questions about invoices, they will be answered for the account owner and admins.

## Changing a role

To change a user's role, log into **Settings > Members**. Both admins and the owner can perform this action. Note that transferring ownership requires the current owner to confirm via email.
